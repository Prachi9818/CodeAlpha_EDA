# CodeAlpha
*💻 Laptop Price Analysis using EDA*
----
📌 PROJECT OVERVIEW
---
This project focuses on performing Exploratory Data Analysis (EDA) on a laptop dataset to uncover meaningful insights about pricing, specifications, and market trends.

The analysis helps in understanding how different features like RAM, brand, weight, and specifications influence laptop prices.

---

📊 Dataset Description
---
The dataset contains 1304 rows and 12 columns, including:

- Company
- TypeName
- Inches
- ScreenResolution
- Cpu
- Ram
- Memory
- Gpu
- OpSys
- Weight
- Price

---

🎯 Objectives
----
- Analyze the structure of the dataset
- Identify trends and patterns
- Understand relationships between variables
- Test hypotheses using visualizations
- Extract meaningful insights for decision-making

---

🔍 Key Questions
---
- Which company offers the most laptops?
- How does RAM affect laptop price?
- Which laptops are most expensive?
- What is the most common configuration?
- Does weight influence pricing?

---

🛠️ Tools & Technologies Used
---
- Python 🐍
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

---

📈 Analysis Performed
---
🔹 Univariate Analysis
--
- Price distribution
- RAM frequency
- Company distribution
- Weight analysis

🔹 Bivariate Analysis
--
- Price vs RAM
- Price vs Company
- Price vs Weight

🔹 Multivariate Analysis
--
- Correlation heatmap

---

📊 Key Insights
---
- Most laptops fall in the mid-price range
- 8GB RAM is the most common configuration
- Premium brands like Apple have higher prices
- Price increases with higher RAM
- Lightweight laptops tend to be more expensive
